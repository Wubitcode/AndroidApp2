AndroidApp2 – Tim Hortons Coffee App

AndroidApp2 is an Android application created for MWD3B – Android Development, Assignment 4. 
The project recreates the core functionality of my previous iOS Tim Hortons coffee-ordering 
application using Kotlin, XML layouts, Activities, and RecyclerView in Android Studio.

Features
Splash screen
Coffee menu loaded from local JSON data
Double Double, Iced Capp, and Vanilla Latte products
Product images, descriptions, and prices
Coffee detail screen
Quantity increase and decrease controls
Add to Cart functionality
Multiple products in one shopping cart
Continue Shopping option
Automatic subtotal and order total calculations
Order confirmation screen
Cart reset after completing an order
Technologies Used
Kotlin
Android Studio
XML Layouts
Android Activities and Intents
RecyclerView
Material Components
JSON
Git and GitHub
Purpose

This project demonstrates Android application development concepts including multiple activities,
navigation with Intents, RecyclerView adapters, local data management, reusable models, 
shopping-cart state management, and responsive XML-based user interfaces.
